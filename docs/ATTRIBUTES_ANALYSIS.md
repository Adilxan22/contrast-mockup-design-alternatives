## 2. Главный вывод — атрибуты структурированы больше, чем предполагалось

`ARCHITECTURE.md` (по итогам первого прохода аудита) исходил из того, что "атрибуты не структурированы, всё текстом в названии", с ожиданием 5–15% SKU на ручную доразметку. Разбор реальной выгрузки показывает более точную и более благоприятную картину:

| Атрибут | Статус | Комментарий |
|---|---|---|
| **Бренд** | Структурирован для 73% SKU | Через поле "Категория" — Poster у этого магазина ведёт категории вида "Black Burn 200гр", "Sebero Гид 25гр", "Alpha Hookah". Бренд = категория без хвоста с весом. |
| **Фасовка (вес)** | Структурирована для тех же 73% SKU | Тоже через "Категорию" — 25гр/200гр/30гр и т.д. прямо в названии категории. |
| **Крепость** | Частично структурирована | Видна через категорию только там, где бренд сам делит линейку по крепости — Spectrum Classic/Hard/Mix, Сарма Легкая/Крепкая, Sebero Black/Classic/Arctic Mix. У большинства брендов (Blackburn, Musthave, Overdose, Hell, Adalya и др.) крепость нигде не указана как отдельное значение. |
| **Вкус** | Не структурирован, но легко извлекается | Всегда свободный текст в "Названии" после бренда и веса, напр. "Табак Blackburn 200 гр Cherry Garden" → вкус "Cherry Garden". Проверено простым парсингом (всё после отметки веса) на 1424 SKU с весом в категории — **сработало на 98.2%** (1399 из 1424). Не сработавшие 25 — один и тот же бренд Deus, где в названии "30 г" вместо "30 гр" (тривиально чинится вторым паттерном). |

**Вывод:** ручная доразметка нужна не на 5–15% ассортимента, как закладывалось индикативно, а по сути на ~2% табачных SKU (опечатки формата) плюс на ~580 SKU из общих категорий аксессуаров (см. п.4) — и то не всегда: бренд там нужен не для каждой категории. Это стоит учесть при финальной цифре по фильтрам каталога (Этап 2 КП, сейчас "от 150 000 ₸") — объём работы меньше, чем закладывалось индикативно.

Практический вывод: приоритет на разметку бренда/фото — 41 бренд из п.3 (1553 SKU, ядро ассортимента — табак и кальяны). Категории из п.4 можно размечать по остаточному принципу или не размечать вовсе, если фильтр по бренду для них не нужен по брифу.

## 5. Что это значит для фото товаров (бриф, п.4)

Список из 41 бренда (п.3) — это и есть список, с которого нужно начинать сбор фото с официальных сайтов поставщиков. По каждому бренду: найти официальный сайт/дистрибьютора → скачать фото по вкусам, где формат позволяет матчинг по названию (после автопарсинга вкуса из п.2 это можно частично автоматизировать — сматчить "название вкуса" с фото на сайте бренда). Для брендов из п.4 (аксессуары) — по остаточному принципу, вручную, объём меньше.

## 6. Рекомендация по сделке

Эта выгрузка даёт основания уточнить цифру по фильтрам каталога (Этап 2 КП) в сторону меньшего объёма работ, чем закладывалось индикативно (5–15% ручной разметки) — реальный объём ручной работы концентрируется в ~580 SKU общих категорий, а не во всём каталоге. Стоит зафиксировать точную цифру с Алуа/шефом, опираясь на эти данные, а не на индикативный диапазон 150 000–350 000 ₸ из `PROJECT_SPEC.md` (раздел 4) — это может сработать в плюс к доверию, так как показывает, что оценка не "накручивается", а наоборот уточняется в меньшую сторону по факту данных.
