# Hookah Market (Contrast)

Интернет-магазин Hookah Market под брендом Contrast. Полное ТЗ, план работ и бэклог — в [docs/PROJECT_SPEC.md](docs/PROJECT_SPEC.md).

## Стек

Next.js (App Router, TypeScript, Tailwind) на Vercel, интеграция с Poster POS API и Yandex Delivery API.

## Запуск

```bash
cd app
npm install
npm run dev
```

Переменные окружения — см. `.env.example` в корне репозитория, скопировать в `app/.env.local`.
