# Contrast — превью сайта

Финальный вид сайта на уже одобренных хиро («Стык») и витрине («1A»), с зафиксированной
типографикой — **Golos Text** (заголовки) + **Onest** (текст и интерфейс), без переключателя
шрифтовых пар. Единственное открытое решение — характер шрифта для хиро-заголовка первого
экрана («Всё для вечера…»): переключатель справа вверху даёт сравнить Golos Text и четыре
более «серьёзных» серифа с сильной кириллицей — PT Serif, Lora, Spectral, Bitter.

Чистый HTML/CSS/JS, без зависимостей и без билд-шага (только Google Fonts с CDN,
фото товаров вшиты в файл как base64 — отдельно грузить не нужно).

## Локальный просмотр
Открыть `index.html` напрямую в браузере — сработает и через `file://`.

## Деплой на Vercel
Отдельный Vercel-проект поверх той же папки `prototype`, без нового репозитория:
1. На vercel.com → Add New Project → импортировать репозиторий `Adilxan22/contrast-mockup-design-alternatives` (можно импортировать его же ещё раз для нового проекта).
2. Root Directory — `prototype/contrast-final`.
3. Framework Preset — "Other", Build Command / Output Directory — по умолчанию.

## Заметки
Верхняя тёмная панель — служебная (подбор шрифта хиро-заголовка для сравнения),
не часть финального дизайна. Как только клиент определится с шрифтом хиро — эту
панель можно убрать вовсе и захардкодить итоговый шрифт.
