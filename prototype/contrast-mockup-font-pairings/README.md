# Contrast — шрифтовые пары

Сравнение шрифтовых пар на уже одобренных хиро («Стык») и витрине («1A»): 6 пар
«заголовок + текст» (включая пару из брендбука Playfair Display + Noah Text и
типографику из последнего брифа MTT Milano + Inter/Manrope) и один вариант
«один шрифт везде» (Noah Text), с переключателем вверху страницы.

Основная пара сайта уже выбрана клиентом — **Golos Text + Onest** (стоит по
умолчанию). Отдельный третий переключатель, «Шрифт хиро-заголовка», подбирает
только характер шрифта для заголовка первого экрана («Всё для вечера…») — сам
Golos Text клиенту для него показался недостаточно «серьёзным»; варианты
(PT Serif, Lora, Spectral, Bitter) не трогают текст и остальные заголовки.

Чистый HTML/CSS/JS, без зависимостей и без билд-шага (только Google Fonts с CDN,
фото товаров вшиты в файл как base64 — отдельно грузить не нужно).

## Локальный просмотр
Открыть `index.html` напрямую в браузере — сработает и через `file://`.

## Деплой на Vercel
Репозиторий уже подключён к GitHub — доставляем эту страницу как отдельный Vercel-проект
поверх той же папки `prototype`, без нового репозитория:
1. На vercel.com → Add New Project → импортировать репозиторий `Adilxan22/contrast-mockup-design-alternatives` (можно импортировать его же ещё раз для нового проекта).
2. Root Directory — `prototype/contrast-mockup-font-pairings`.
3. Framework Preset — "Other", Build Command / Output Directory — по умолчанию.

## Заметки
Верхняя тёмная панель — служебная (переключатель шрифтовых пар для сравнения),
не часть финального дизайна.
